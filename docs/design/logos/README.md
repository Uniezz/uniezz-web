# Uniezz logo explorations

50 symbol-only app and web logo directions, each exported as a 512 × 512 PNG.

The six retained concepts are the original design nodes **VhAtb, n7zgzC, B7soM, bFNpR, r6ayk, and ZR4Pf** (01, 03, 07, 08, 11, and 31). The remaining 44 were redrawn around Uniezz as a student community for campus life, meeting people, chat, and plans around Lublin.

No logo contains the Uniezz wordmark or other text. The concept names and numbers are only in the board and this index.

- `512/`: all 50 icon files
- `contact-sheet.png`: board preview
- `concepts.json`: names and short descriptions
- `../uniezz-web-app.pen`: editable design board
